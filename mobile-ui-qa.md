# Mobile UI QA

After the mobile refresh, the Home page was captured at 390×844 and 320×780. The header remains compact, the mobile menu trigger remains visible, the hero copy and image fit within the viewport, CTA buttons span the available width, service cards stack vertically, the six-step process uses a two-column layout, and the about/stats/contact/footer sections remain readable without visible horizontal overflow.

The 320px capture uses smaller brand typography, reduced hero height, two-column proof points, tighter process spacing, and a compact footer to preserve the full layout on narrow screens.
